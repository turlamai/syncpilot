Linux 桌面版 Resilio Sync 客户端

原汁原味的 Resilio Sync 体验， 终于登陆 Linux。

SyncPilot 把官方 Resilio Web UI装进原生桌面窗口，并在背后托管官方 rslsync守护进程。每一屏都是官方界面——无需重新学习。 SyncPilot 只做外壳：自有界面仅出现在标题栏、状态栏、引导页、设置窗、更新卡与托盘六处——管 Resilio，不变成第二个 UI。

为什么是 SyncPilot

关键处用官方，
该原生处就原生。

窗口主角始终是官方 Resilio 界面：文件夹、伙伴、传输、激活，版本与你的 rslsync 构建一致——不重绘、不改词、不翻译。SyncPilot 只补齐外壳该做的事。

零界面偏差

窗口内嵌的就是官方 Resilio Web UI——与 Windows、macOS 客户端相同的界面与工作流；SyncPilot 不重绘、不改词、不翻译，没有任何会落后的二次实现。

守护进程全生命周期

一键启停，可接管已在运行的守护进程；崩溃看门狗按指数退避自动重启。相位（运行中/启动中/已停止/已崩溃/失败）在标题栏与底部状态栏双可见，永不静默。还可选在应用退出后继续保活。

首次运行与升级

机器上还没有 rslsync？一键从官方 CDN 下载，经 sha256 校验装入 ~/.local/bin。数据路径跨版本不变，解压新版即可继续同步。

自启、托盘与设置

XDG autostart 开机自启、单实例窗口唤起、关闭窗口隐藏到托盘（打开 / 设置 / 退出），还有独立的原生设置窗口管理守护进程、端口与凭据。

在线更新

每天后台检查一次签名 manifest，三步走：发现新版本 → 下载并经 Ed25519 验签 → 按安装形态手动应用。下载前必先询问，rslsync 数据绝不触碰。

默认安全

Web UI 仅留在 127.0.0.1，经注入认证的环回代理访问——不弹登录框，守护进程绝不响应未认证请求。

状态一目了然

每个文件夹五种状态直接来自官方数据：已同步、同步中（进度与剩余时间）、已断开连接（上次同步）、正在扫描、出错；底部状态栏常驻全局 ↓/↑ 速度。

密钥与对端

文件夹详情提供读写/只读密钥卡，一键复制给其他设备加入；对端连接态一眼可辨——同步中、已连接、正在连接、离线，附速率与最近同步。

许可门禁如实呈现

Resilio 3.x 添加文件夹前需先激活许可。SyncPilot 不伪装也不代劳：未激活/试用中以横幅如实呈现，激活与添加都在官方界面完成，SyncPilot 不设任何付费层。

上手步骤

三步上手

与在其他平台安装官方客户端的体验一致。

安装

从 release 页获取 deb、rpm、AppImage 或 tar.gz，安装即用——GTK 4 与 WebKitGTK 在 Ubuntu 24.04+ 上系统自带。

启动

SyncPilot 启动官方守护进程，并把窗口交给官方界面。还没有 rslsync？一键获取。

同步

通过官方向导完成激活并添加文件夹——与 Windows、macOS 上完全一致。

本地控制，明确的对端文件传输。SyncPilot 在本地生成守护进程凭据，官方 UI 经仅环回的代理提供服务，自身不带任何遥测。官方二进制向对端传输配置的文件，也可能使用发现或中继服务。
