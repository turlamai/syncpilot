# SyncPilot — 设计与交互契约

## 当前决定（2026-11-14）

用户要求：与 Resilio Sync 桌面客户端一致，不自行重新设计。

当前修改范围为 `prototype/folders.html`。它以 Resilio 官方《Sync Main View (Desktop)》中 2024-08-28 的主界面截图为具体参照，不再沿用旧版原型自创的侧栏、状态徽章、宿主状态栏、相位芯片或主题切换。此决定覆盖此前对此页面的全部相反描述。

参照来源：
- 文档：https://help.resilio.com/hc/en-us/articles/204755009-Sync-Main-View-Desktop
- 官方图片：https://syncapp.zendesk.com/hc/article_attachments/32823473877907
- 本地品牌素材与来源记录：`assets/resilio/sync-wordmark.png`、`assets/resilio/credits.json`。

## 文件夹主视图

### 布局

- 深蓝色横向工具栏：左侧添加入口、居中官方 Sync 标识、右侧文件夹 / 共享文件 / 历史 / 首选项入口。
- 文件夹入口采用官方参照的蓝色选中底。
- 第二行保留全部 / 已连接 / 已断开连接 / 本地筛选及搜索。
- 主体使用白底表格，默认列为类型图标、名称、状态、在线对端。
- 在线对端显示在线数量与总数，点击打开对端入口；不以设备侧栏替代。
- 列标题提供列显示菜单；右键标题区同样打开菜单；菜单项按官方顺序（接收、发送、进度、路径、所有者、大小、本地大小、文件数、本地文件数、添加日期、同步日期、上次传输）。「进度」无独立列，切换状态列内的百分比显示。
- 右键 share 行打开官方 share 菜单（打开文件夹 / 共享 / 文件夹偏好设置）；条目仅演示，不执行真实操作。
- 工具栏通知图标在文件夹入口左侧，非活动暗置（官方文档记载），点击给出演示说明；不伪造未读数。
- 底部保留官方截图中的暂停和传输活动入口。它们仅作原型演示，不构成 rslsync 版本能力承诺，也不调用真实服务。
- 不显示教学截图中的红色标注序号。
- 不添加自行设计的侧栏、圆角状态胶囊、渐变画布、主题按钮、凭据或代理实现信息。

### 内容与交互边界

- 界面按既有项目语言采用中文；官方参照图为英文，当前中文不是从实际中文客户端逐字采集的文案。
- 保留原型既有六个示例文件夹及路径、容量和进度。所有数据都不是实际同步状态。
- 搜索、连接筛选和列显隐在浏览器中生效。
- 添加、密钥、打开系统文件夹、对端与工具栏入口显示演示说明；不伪造系统选择器、文件访问、提交成功或真实设备列表。
- 对端计数保留示例数据；不编造未知的设备明细。
- 未提供数据的可选列显示破折号，不制造日期或文件统计。
- 图形以 SVG 构建；官方品牌标识使用本地提取的官方素材，不以自创图标替代。
- 页面无暗色主题：不自行增加参照中没有的主题。

## 其余原型（2026-11-18 · issue #35 官方视觉语言对齐）

`boot.html`、`empty.html`、`folder-detail.html`、`settings.html`、`update.html` 与 `shared.css` 已统一到官方客户端视觉语言（导航蓝 `#000044` 条、白底、`#1686ff` 主操作、`#087bea` 链接、`#00a6ce` 选中页签、`#f8f8fa` 条底、`#dadada` 分隔、3px 控件圆角），并去掉旧稿自创的红绿灯、相位芯片、宿主状态栏与主题切换，使原型与真实宿主结构（原生窗口装饰、居中引导卡、独立设置窗、浮层对话框）相符。`shared.css` 即为这套参数的载体；主视图 `folders.html` 样式仍独立自带。

- `empty.html`：主视图空态，官方语义「还没有同步文件夹 / 添加一个即可开始同步」，工具栏与主视图同构。
- `boot.html`：引导卡（自有表面，不冒充 Resilio 品牌），与真实宿主一致为普通窗口 + 居中卡。
- `settings.html`：SyncPilot 设置窗，按官方 Sync Preferences 文档的分区结构组织（守护进程/设备/桌面/更新/关于）。
- `update.html`：更新就绪对话框（浮层第三层），官方对话框样式。
- `folder-detail.html`：样例评审页。官方客户端没有独立详情页（对端入口在主视图 X of Y，偏好在对话框）；本页保留供评审，归属边界不变。

**本组页面的不确定处（退出条件条款 4）**：官方偏好设置对话框、文件夹偏好与分享对话框截图未能采集（下载 TLS 失败），以上页面版式按主视图语言 + 文档结构推导，未经像素级参照确认；官方空态参照取自既有官方截图（与 `site/screenshot.png` 同源）。这些页面在「完全一致」口径下只算视觉语言对齐，不算逐像素对齐。

## 不变式与退出条件

1. 实际客户端或官方截图是参照，旧稿中的「官方」注释不能作为真实性证据。
2. 信息架构、术语、视觉与操作均不得以家族风格代替官方参照。
3. 不把原型状态冒充后台服务状态，不把原型交互冒充真实同步操作。
4. 官方资料不能确认的版本差异、字体、本地化或未展示的状态必须保留不确定性。
5. 当前交付是主视图修改，不是全部客户端页面、后台接入或逐像素验收完成。
6. 完全一致的退出条件：固定具体客户端版本与语言；全部目标页面有直接参照；状态和操作逐项对齐；用户确认。不得仅凭本页已写入就宣布全部完成。


## 2026-11-18 · 主视图修复与官方元素补齐（issue #34）

2026-11-18 审查（对照官方截图 + 官方帮助文档逐项核对）发现四项缺口，本日修复，均以官方参照为准：

1. **搜索过滤失效**：内联脚本 `querySelector('#search')` 命中 DOM 顺序更靠前的 SVG `<symbol id="search">`，监听器从未挂在输入框上。symbol 改名 `icon-search`、监听器改 `input#search` 双保险。教训：图标 symbol 与表单控件不得共用 id。
2. **通知铃铛补齐**：官方帮助文档记载的主界面元素，非活动暗置，点击给出演示说明。
3. **share 行右键菜单补齐**：官方记载的 share 菜单（打开/共享/偏好），演示条目。
4. **列显隐菜单对齐官方顺序**：12 项按官方文档顺序排列；「进度」沿用现状（切换状态列百分比显示，无独立列）。

仍不满足完全一致退出条件：其余 5 屏为旧稿、固定客户端版本与语言未锁定、宿主未按本页对齐（#30 跟踪）。

## 2026-11-15 · 原型交互补齐

入口为 prototype/folders.html。设置入口可达，端口限制 1024–65535；新增本地示例、详情页、历史和共享入口有反馈，不调用 Resilio。外观还原页与系统外壳的状态样本保持各自范围。

根级 index.html 只负责首次进入主界面；页面切换直接到目标界面，不再保留页面目录。原型运行脚本 prototype-runtime.js / prototype-flow.js 只表达浏览器内的交互合同；正式产品业务仍由既定引擎实现。真实设备、模型和发布服务均未连接。凭据演示不保存密钥，破坏性示例与派发保留确认和取消。

这些是可评审的增量改动，未替用户勾选满意度、HIG 最终验收或设计冻结条件。
