#### 六屏亮暗语义对（2026-11-22）

具体亮暗色值仅在 `prototype/shared.css` 的 `--theme-light-*` / `--theme-dark-*` 对中维护；下表记录语义，不复制第二份数值表。有效角色通过别名映射到所选主题。

| 语义 | 成对 token | 使用范围 |
|---|---|---|
| 画布 | `--canvas`、`--bg`、`--canvas-start/mid/end` | 整体画布和已有壳层背景；暗态均为深灰，不使用纯黑画布 |
| 表面 | `--surface`、`--raised`、`--bar` | 列表、卡片、字段、浮层层级 |
| 文字 | `--ink`、`--mute`、`--inverse` | 正文、辅助和反向前景 |
| 边界 | `--line`、`--control-border` | 装饰性分隔、重要控件轮廓；后者最低 3:1 |
| 强调 | `--accent`、`--accent-foreground`、`--accent-hover`、`--accent-soft` | 主要动作、链接、进行态；暗态强调前景独立定义 |
| 选中 | `--selected`、`--selected-foreground`、`--selected-strong`、`--selected-strong-foreground` | 选中底/文字与强选中图形；保留非颜色选中提示 |
| 焦点 | `--focus` | 可见键盘焦点，不与普通边线混用 |
| 成功 | `--ok`、`--ok-soft` | 完成、已校验；配勾或状态文字 |
| 警告 | `--warn`、`--warn-soft` | 许可/注意；配完整文字或警告符号 |
| 错误 | `--err`、`--err-soft` | 磁盘不足等错误；配错误文字和图形 |
| 工具栏和菜单 | `--nav*`、`--popup*` | 保留现有结构与品牌；弹出菜单各态有独立前景 |
| 悬停、图标和遮罩 | `--row-hover`、`--folder`、`--overlay`、`--dialog-overlay`、`--shadow-*` | 悬停、目录图形、原有浮层与阴影 |

既有命名 `--blue/cyan/link/text/muted/white/green/orange` 仅作语义别名，禁止在六屏或运行脚本中重新写颜色数值。正文/辅助/状态文字按至少 4.5:1 配色，大字至少 3:1，重要控件边界/图形至少 3:1；细分隔线不作为控件唯一识别线。

#### 主题机制（2026-11-22）

- 六屏均在共享 CSS 前同步载入本地 `theme.js`，首屏即解析主题；根节点 `data-theme` 表示实际亮暗，`data-theme-preference` 表示选择来源。
- 无手动偏好时跟随 `prefers-color-scheme`；系统改变时立即更新。CSS 在脚本不可用时仍提供系统暗态的 token 回退。
- 主题按钮沿用 `iconbtn` 角色：点击在亮暗之间切换；Shift+点击或 Shift+回车/空格恢复系统跟随。可访问名称和 tooltip 包含当前模式、下一动作与恢复方式，`aria-pressed` 表示当前是否为暗态。按钮外形以「2026-11-26 · 原型对齐家族基线」为准：`◐` 字形已换为线框图标。
- 仅显式 `light/dark` 偏好保存到 localStorage 的 `syncpilot:theme`；恢复系统时删除该项。支持跨页重载与同源标签页同步。
- localStorage 被禁止、损坏或不可用时安全回退；当前页仍能切换，不假装跨页持久化成功。旧运行脚本不再读写相互冲突的 `.dark` 状态。
- boot 在原标识行放置按钮；folders 使用原底栏；其余四屏使用原标题栏。六屏不新增导航层级。
- 普通弹窗、动态示例、原生字段、按钮前景、菜单与焦点均消费共享 token；品牌位图不做反相处理。
- 保留现有字号、间距、圆角与页面组件词汇。仅为已有进度文字解除错误的固定高度裁切，并约束密钥行的收缩；不重排桌面信息架构。

本页不沿用其余原型的圆角与色彩体系。原生窗口装饰未在截图参照中给出，不编造平台标题栏。

### 内容与交互边界

- 界面按既有项目语言采用中文；官方参照图为英文，当前中文不是从实际中文客户端逐字采集的文案。
